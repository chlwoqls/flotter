# 3주차 과제 — 작은 기능 요구사항 컨텍스트

## 1. 사용자 목표와 스토리

- **기능 이름:** StudyGoal 추가·완료 전환
- **대상 사용자:** 앱프로그래밍을 배우며 하루의 학습 계획을 관리하는 학생
- **해결하려는 문제:** 오늘 해야 할 학습 내용을 한곳에 기록하고, 어떤 항목을 마쳤는지 빠르게 구분하기 어렵다.
- **사용자 스토리:** 학습자로서 나는 오늘의 학습 목표를 등록하고 완료 표시를 하고 싶다. 그래서 남은 학습 항목을 한눈에 확인할 수 있다.

## 2. 기능 범위와 제약

### 포함 범위
1. 텍스트 입력란에 학습 목표를 입력한다.
2. 유효한 목표를 추가 버튼 또는 키보드 완료 동작으로 목록에 추가한다.
3. 비어 있거나 공백뿐인 입력은 추가하지 않고 오류 문구를 표시한다.
4. 체크박스로 목표의 완료 상태를 전환한다.
5. 완료 항목에 취소선과 상태 문구를 표시한다.

### 제외 범위
1. 앱을 종료한 뒤에도 목표를 유지하는 영구 저장 기능
2. 계정 로그인 및 여러 기기 간 동기화
3. 목표 마감일, 알림 및 반복 일정
4. 목표 수정 및 삭제 기능

### 입력
- 사용자가 입력한 학습 목표 문자열
- 사용자가 누른 추가 버튼 또는 체크박스 상태

### 출력
- 학습 목표 목록
- 빈 입력에 대한 `목표를 입력하세요` 오류 문구
- 완료/진행 중 상태와 완료 개수

### 예외
- 입력값이 비어 있거나 공백만 있는 경우 목록에 추가하지 않는다.
- 앞뒤 공백은 제거한 뒤 목록에 추가한다.

### UI 제약
- 입력 오류는 입력란에 표시한다.
- 완료 상태는 체크박스, 상태 문구, 취소선으로 구분한다.
- 버튼과 체크박스는 기본 Flutter 상호작용 위젯을 사용한다.

## 3. 수용조건과 완료 증거

### AC1 — 정상 입력
- **Given:** 목표 입력란에 `Dart 문법 복습하기`가 입력되어 있다.
- **When:** 사용자가 `목표 추가` 버튼을 누른다.
- **Then:** 해당 목표가 목록에 추가되고 입력란이 비워진다.
- **증거 파일:** `evidence/AC1_정상추가.png` (실행 후 캡처 추가)

### AC2 — 빈 값 입력
- **Given:** 목표 입력란이 비어 있거나 공백만 입력되어 있다.
- **When:** 사용자가 `목표 추가` 버튼을 누른다.
- **Then:** 목록은 변경되지 않고 `목표를 입력하세요` 오류 문구가 표시된다.
- **증거 파일:** `evidence/AC2_빈값오류.png` (실행 후 캡처 추가)

### AC3 — 완료 상태 전환
- **Given:** 등록된 학습 목표가 목록에 표시되어 있다.
- **When:** 사용자가 해당 목표의 체크박스를 누른다.
- **Then:** 완료 상태, 취소선, 완료 개수가 갱신된다.
- **증거 파일:** `evidence/AC3_완료전환.png` (실행 후 캡처 추가)
