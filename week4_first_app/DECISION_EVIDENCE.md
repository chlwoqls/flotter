# 4주차 과제 — 위젯 결정 근거표

아래 공식 문서 링크를 직접 열어 확인하고, 제출 전에 본인이 확인한 내용과 실행 결과를 기록한다.

| 위젯 | 공식 문서 위치 | 확인할 내용 | 현재 화면에 적용한 이유 |
|---|---|---|---|
| `Scaffold` | https://api.flutter.dev/flutter/material/Scaffold-class.html | Material 화면의 기본 구조 | 앱 바와 본문 구성 |
| `AppBar` | https://api.flutter.dev/flutter/material/AppBar-class.html | 상단 앱 바 | 화면 제목과 초기화 아이콘 표시 |
| `Text` | https://api.flutter.dev/flutter/widgets/Text-class.html | 문자열 표시 | 제목, 완료 개수, 상태 문구 표시 |
| `Icon` | https://api.flutter.dev/flutter/widgets/Icon-class.html | 아이콘 표시 | 학습 및 완료 상태 표현 |
| `Row` | https://api.flutter.dev/flutter/widgets/Row-class.html | 가로 배치 | 요약 아이콘과 텍스트를 나란히 배치 |
| `Column` | https://api.flutter.dev/flutter/widgets/Column-class.html | 세로 배치 | 제목·개수·진행 막대 배치 |
| `ListView` | https://api.flutter.dev/flutter/widgets/ListView-class.html | 스크롤 목록 | 여러 학습 항목 표시 |
| `CheckboxListTile` | https://api.flutter.dev/flutter/material/CheckboxListTile-class.html | 체크박스와 타일 결합 | 체크 입력으로 완료 상태 변경 |
| `FilledButton` | https://api.flutter.dev/flutter/material/FilledButton-class.html | 강조 버튼 | 학습 항목 추가 |
| `LinearProgressIndicator` | https://api.flutter.dev/flutter/material/LinearProgressIndicator-class.html | 선형 진행 표시 | 완료 비율 표시 |
